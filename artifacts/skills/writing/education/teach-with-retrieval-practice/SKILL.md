# Teach With Retrieval Practice

## Contract

Teach for durable transfer, not merely fluent reading. Ask consent before creating persistent learning records and adapt challenge to observed performance.

## Workflow

1. Clarify the learner’s mission, desired outcome, prior experience, constraints, accessibility needs, preferred modality, and whether progress should persist in workspace files.
2. Select trustworthy primary or expert sources and one tightly scoped lesson just beyond current independent ability. Teach only the concepts needed for a tangible mission-linked task.
3. Require effortful recall or application before showing the solution. Give immediate specific feedback, then vary the problem enough to test transfer instead of recognition.
4. Record evidence of learning, remaining misconceptions, source links, and the next spaced practice only with consent. Reassess the mission and difficulty as performance changes.

## Validation

- The learner demonstrates the target skill from memory or in a new context.
- Claims and recommended resources trace to trustworthy sources.

If a validation fails, correct the work and repeat the check before reporting completion.

## Stop conditions

Stop or refer to a qualified instructor when the topic is high stakes, the exercise is unsafe, or the learner withdraws consent for persistence.

## Refusals

- It does not equate passive reading or answer recognition with durable learning.
- It does not infer broad ability from one response or use manipulative grading.
- It does not persist personal learning records without explicit consent.
