# Architecture decisions

Architecture decision records capture durable choices that future contributors would otherwise need to rediscover. Add a numbered Markdown file when a change alters a long-lived interface, trust boundary, release control, storage contract, or repository policy.

Each record states its status, date, context, decision, consequences, and replacement relationship when superseded. Records are append-only after acceptance except for typo or link corrections; a new decision supersedes an old one.
