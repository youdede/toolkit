# Support

Use GitHub Issues for reproducible defects and bounded feature proposals. Search existing issues first, use the appropriate issue form, and include the toolkit version, target runtime, command, expected result, actual result, and a minimal reproduction.

General consulting, private project debugging, migration execution, and guaranteed response times are outside the community support boundary. A maintainer may close requests that cannot be reproduced, omit necessary evidence, duplicate existing work, or ask the toolkit to exceed a runtime's documented authority.

Report suspected vulnerabilities through the private process in [`SECURITY.md`](SECURITY.md), never through a public issue.
